# AuraScribe icon

`aurascribe-icon.png` was created with the built-in image generation tool, then copied into this project. The macOS AppIcon variants are standard `sips` resizes. The menu bar companions are deliberately monochrome template images, drawn reproducibly by `swift tool/generate_tray_icons.swift`; macOS supplies their light/dark contrast. Recording and processing add distinct status dots.

Generation prompt:

> Use case: logo-brand. Create one finished macOS app icon for AuraScribe, an offline voice dictation app. A distinctive simple sculptural mark: three smoothly curved vertical sound ribbons that together suggest an open letter A and a flowing spoken voice, no microphone pictogram, no text. Cool pearl and sea-glass teal ribbons, subtle dimensional polished ceramic material, on a deep ink rounded-square tile. Calm premium native Mac aesthetic, excellent silhouette and strong contrast at small sizes. Centered single icon occupying 84% of a square canvas with transparent space outside the rounded tile, no mockup, no cast shadow outside tile, no extra objects or lettering.

Transparent background requested. No external runtime image dependency remains.
